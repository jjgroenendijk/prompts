# Quality

* [Enforce With Git Hooks And CI](enforce-with-githooks-and-ci.md) - Enforce rules by machine: git hooks locally, CI as the pull request backstop.
* [Keep Config Files Out Of Root](keep-config-files-out-of-root.md) - Package, build, test, and lint config lives in purpose dirs, not the repo root.
* [Lint And Format Every Language](lint-and-format.md) - Every language needs linter and auto-formatter coverage, Markdown included.
* [Low Nesting Depth](low-nesting-depth.md) - Keep nesting shallow; use early exits and guard clauses instead of nested blocks.
* [Max 600 LOC Per File](max-600-loc-per-file.md) - Cap hand-written files at 600 lines; generated and vendored files are exempt.
* [Max Line Length](max-line-length.md) - Cap hand-written lines at 100 chars; URLs, hashes, generated files are exempt.
* [Strict Linting](strict-linting.md) - Strictest ruleset, warnings as errors, every inline suppression justified.
