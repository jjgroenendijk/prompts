# Commits

* [Commit Atomicity](commit-atomicity.md) - One logical change per commit, each independently checkable and green.
* [Commit Body Sections](commit-body-sections.md) - Non-trivial commits carry Context, Change, Rationale, Impact/Risk, Tests.
* [Commit Message Format](commit-message-format.md) - Imperative subject near 50 chars, blank line, then a body explaining what and why.
* [Conventional Commits](conventional-commits.md) - Use type(scope?): subject, with allowed types and explicit breaking-change markers.
* [Issue Linking](issue-linking.md) - Link issues with a Fixes or Refs footer, or state in the body why none exists.
* [No AI Attribution Trailers](no-ai-attribution.md) - Forbid AI attribution trailers; allow Fixes, Refs, BREAKING CHANGE, human sign-off.
