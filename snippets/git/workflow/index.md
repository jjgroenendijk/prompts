# Workflow

* [Incremental Commits](incremental-commits.md) - Commit in small meaningful increments; keep WIP checkpoints local until green.
* [Quality Gates](quality-gates.md) - Run tests before every commit and keep shared branches free of failing commits.
* [Shared Git Hooks](shared-githooks.md) - Track hooks in .githooks/ with thin wrappers running numbered scripts per hook.
