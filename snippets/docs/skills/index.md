# Skills

* [Skill Content Hygiene](skill-content-hygiene.md) - Write only what the agent lacks, with one term per concept and no dated text.
* [Skill Evals First](skill-evals-first.md) - Write three evaluations and a no-skill baseline before writing the skill body.
* [Skill Name and Description](skill-name-and-description.md) - Name skills by activity; describe what they do and when to use them, in third person.
* [Skill Progressive Disclosure](skill-progressive-disclosure.md) - Keep SKILL.md under 500 lines and link reference files one level deep.
